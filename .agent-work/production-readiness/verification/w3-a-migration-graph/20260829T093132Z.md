# Independent verification — W3-A migration graph and reversibility

## Claims under test

Restated from the executor log as falsifiable propositions:

1. **Topological ordering.** `loader.topological_sort` / `MigrationGraph.topological_order`
   produce deterministic Kahn's-algorithm order with name-sorted tie-breaks; cycles raise.
2. **Target upgrade/downgrade.** `MigrationGraph.upgrade_plan(target)` returns pending
   migrations up to and including `target`; `downgrade_plan(target)` returns applied
   migrations strictly after `target` in reverse topological order; irreversible migrations
   in a downgrade plan raise `FerrumMigrationError`.
3. **Checksum enforcement preserved (W1-C).** `ledger.verify_checksum` /
   `verify_checksum_on_conn` are untouched; `recovery_guidance` reports mismatches.
4. **Status/history + recovery guidance.** `MigrationGraph.status` returns per-migration
   state (`applied`/`pending`/`checksum_mismatch`/`unknown`); `recovery_guidance` returns
   actionable hints for mismatches, out-of-order applies, and irreversible heads.
5. **Reversible ops.** `base.is_reversible` / `reverse_classifications` query
   `reverse_operations`; integration tests verify rename/default/nullability/index
   reversibility against live PostgreSQL.
6. **Destructive/type-narrowing classification preserved (W1-C).** `_is_op_destructive` and
   `operations.AlterColumn.classification` are untouched; `OfflineSqlMigration.has_destructive`
   reuses `_is_op_destructive`.
7. **Data migration callables + transaction policy.** `DataMigration` base +
   `run_data_migration` runner; policies `"required"` wraps in `conn.transaction()`,
   `"none"` runs in autocommit; unknown policy rejected; callable failure wrapped as
   `FerrumMigrationError` with `type(exc).__name__` only.
8. **No automatic source-code execution from untrusted files.** `run_data_migration`
   refuses `is_trusted=False` before any execution.
9. **Offline SQL with checksums + phase annotations.** `generate_offline_sql` returns
   `OfflineSqlPlan` with per-migration `digest` (matches `ledger.compute_digest`) and
   `phase` tags (`pre_tx`/`tx`/`post_tx` from `_split_ops_by_phase`); no DB I/O.
10. **W1-C advisory lock / transactional DDL / destructive confirm PRESERVED.**
    `_apply_postgres` unchanged: `pg_advisory_xact_lock`, `conn.acquire() +
    raw_conn.transaction()`, `record_applied_on_conn` atomic, `_is_op_destructive`
    confirm gate, env gate, token gate.
11. **No scope leaks.** Only W3-A owned paths changed; parallel workstream files
    (W2-E/W4-C/W4-D) are not W3-A scope leaks.
