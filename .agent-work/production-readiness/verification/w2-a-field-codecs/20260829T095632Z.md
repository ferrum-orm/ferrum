# Independent verification — W2-A (typed field codecs)

## Claims under test

Restated as falsifiable propositions against AGENTS.md §2, §3, §8 and the
task contract acceptance criteria:

1. **C1 — FieldCodec protocol**: typed `encode_bind`/`decode_result`/`redact`
   contract; pure functions with no I/O, no async, no Rust core involvement.
2. **C2 — Nested Pydantic JSONB**: `NestedModelCodec` and
   `NestedListModelCodec` round-trip models/lists through JSONB; decode uses
   `model_construct` (ADR-003 trusted fast path).
3. **C3 — Encrypted codecs with key-provider injection**: `EncryptedStringCodec`
   and `EncryptedJSONCodec` receive keys via `KeyProvider` protocol; no
   hardcoded keys anywhere in source; authenticated encryption (encrypt-then-MAC).
4. **C4 — PostgreSQL type coverage**: citext, inet, bytea, arrays, enums,
   vector dimensions, custom domains all have codec kinds and field-type
   overrides; DDL emits correct PostgreSQL types.
5. **C5 — Hydration constructs declared nested types**: `decode_result` uses
   `model_construct` for nested models (no revalidation, ADR-003).
6. **C6 — Metadata immutability/IDE-visibility/migration-awareness/exclusion**:
   `CodecMeta` is a frozen dataclass; `FieldMeta.codec_meta`/`domain_name`
   are stored at class-definition time; `to_metadata_dict()` excludes
   `codec_meta`, `codec_pii`, `codec_key_id`, `codec_domain` from the Rust
   boundary payload (only `field_type` is sent for SQL casting).
7. **C7 — Round-trip tests**: deterministic and randomized round-trips for
   encrypted string and JSON codecs.
8. **C8 — Key rotation/failure/malformed ciphertext/PII redaction tests**:
   key rotation succeeds; wrong key rejected; malformed ciphertext fails
   safely; tampered MAC/ciphertext rejected; `redact()` never returns raw
   value or key material.
9. **C9 — No scope leak**: only owned paths changed; W2-B/W3-B/W4-B parallel
   changes are NOT W2-A scope leaks.
10. **C10 — Revert instructions sufficient**: smallest safe inverse preserves
    all other workstreams.

`domain_name`, or `codec_model`. Confirmed by `TestCodecMetadataExclusion`

`test_field_type_sent_in_metadata_dict`). ✅
