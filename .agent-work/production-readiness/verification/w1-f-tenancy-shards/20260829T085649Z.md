## Adversarial checks

- **Injection via schema name**: `schema_transaction(conn, "public; DROP TABLE x")`
  → `FerrumCompileError(category="invalid_identifier")` raised BEFORE opening
  the transaction (regex fails first). Even if the allowlist were bypassed,
  the regex prevents `;`, spaces, quotes, and dots. ✓
- **Admin GUC confusion**: `platform_admin_transaction(conn, admin_guc="app.team_id")`
  → `FerrumCompileError(category="guc_name_not_allowed")` — tenant-id GUC is
  not in `ALLOWED_ADMIN_GUC_NAMES`. ✓
- **Registry partial-open leak**: `start()` with one bad DSN → already-opened
  pools are closed (`good.close.assert_awaited_once()`); registry is unusable
  after. Live test `test_registry_start_rolls_back_on_failure` confirms. ✓
- **Double-close**: `close()` is idempotent — `conn.close.assert_awaited_once()`
  after two `close()` calls. ✓
- **Pool reuse GUC leak**: cross-tenant test opens two sequential
  `tenant_transaction`s on the same `pg_conn`; after the first commits, the
  second sees only its own GUC, and the pool read after both sees no leaked
  GUC. ✓
