## Decision: `changes_required`

### Findings

#### D1 — `mise run lint-rust` fails (blocking)

- **Severity**: blocking
- **Evidence**: `mise run lint-rust` exits 1. `cargo clippy --workspace
  --all-targets -- -D warnings` treats the `match_same_arms` pedantic warning
  as an error. The warning is on `crates/ferrum-sql/src/emit.rs:1242` where
  `FieldType::Domain => "text"` has the same body as
  `FieldType::Text | FieldType::Enum => "text"`.
- **Affected criterion**: C10 (ci-local), AGENTS.md §8 (lint passes for touched
  code).
- **Smallest required correction**: Merge the match arm:
  ```rust
  FieldType::Text | FieldType::Enum | FieldType::Domain => "text",
  ```
  and remove the separate `FieldType::Domain` arm and its 4-line comment block.
  The `Domain` cast intent is already documented by the existing `Text`/`Enum`
  arm semantics.

#### D2 — Missing test coverage for new safety guards (blocking)

- **Severity**: blocking
- **Evidence**: The three new safety guards — `_MAX_SELECT_RELATED_DEPTH`
  (queryset.py:83), duplicate detection in `select_related()`
  (queryset.py:1658-1666), and `_MAX_TOTAL_JOINS` (queryset.py:85) — have no
  tests. `TestSelectRelatedGuards` only tests non-relation rejection and
  immutability-on-error. No test verifies that exceeding 5 relations, adding a
  duplicate relation, or exceeding 12 total JOINs raises `FerrumCompileError`.
- **Affected criterion**: AGENTS.md §2.7 ("No ORM feature ships without
  tests"), §7 ("New behavior → new tests in the same diff").
- **Smallest required correction**: Add unit tests:
  1. `test_select_related_rejects_duplicate_relation` — call
     `select_related("author", "author")` and assert `FerrumCompileError`.
  2. `test_select_related_rejects_depth_exceeding_limit` — call
     `select_related` with >5 relations and assert `FerrumCompileError` with
     "exceeds limit".
  3. `test_build_ir_rejects_total_join_count_exceeding_limit` — construct a
     QuerySet with >12 JOINs (e.g., via relation-filter lookups +
     `select_related`) and assert `FerrumCompileError` at `_build_ir` time.

#### D3 — Dead code: `_DEFAULT_UNBOUNDED_LIMIT` (non-blocking)

- **Severity**: non-blocking (code quality)
- **Evidence**: `_DEFAULT_UNBOUNDED_LIMIT: int = 0` (queryset.py:93) is
  declared but never referenced. The comment says "see guard in all()" but no
  guard exists in `all()`. YAGNI violation per AGENTS.md §7.
- **Smallest required correction**: Remove the constant and its comment, or
  wire it up with a test. Removing is the minimal safe fix for this run.
