## Execute

### Decisions

1. **acquire_timeout on every path**: Refactored `AsyncpgDriver.fetch/fetchrow/fetchval/execute`
   to use `pool.acquire(timeout=...)` + raw conn call + release, instead of
   `pool.fetch()` which doesn't accept a timeout. `transaction()` also uses
   the timeout-aware acquire. `_acquire_cm()` helper centralizes the timeout logic.

2. **Distinct idle lifetime vs hard max age**: `max_lifetime` (legacy) and
   `max_idle_lifetime` (new, clear name) both map to asyncpg's
   `max_inactive_connection_lifetime` (idle recycling). `max_connection_age` (new)
   is a hard max age — tracked via connection birth times in the init callback
   and enforced best-effort via `expire_connections()`. Both are distinct config
   knobs with clear names.

3. **New config knobs**: `command_timeout`, `statement_cache_size`, `ssl`,
   `server_settings`, `application_name` wired to `asyncpg.create_pool()`.
   `application_name` is folded into `server_settings` (asyncpg's mechanism).

4. **Failover-safe validation/replacement**: No unconditional pre-ping. On
   failover-category errors, `expire_connections()` is called to force pool
   recycling. This is the failover-safe replacement path.

5. **Event-based shutdown**: Subclassed `_LifecycleGuard` as
   `_EventLifecycleGuard` in `connection.py` (owned path — runtime.py is NOT
   owned). Uses `asyncio.Event` instead of busy-poll `drain_inflight()`.
   `end()` sets the event when inflight reaches 0; `close()` awaits the event
   with the drain timeout. Forced drain timeout is reported as
   `FerrumTimeoutError(category="timeout")` after the pool is closed (no leak).

6. **Typed PoolStats**: `PoolStats` dataclass in `drivers/postgres.py` with
   fields: size, idle, acquired, waiters (-1 if unavailable), min_size,
   max_size, inflight, accepting, closing. `Connection.pool_stats()` combines
   asyncpg pool internals with Ferrum lifecycle state. Uses defensive
   `getattr` for asyncpg private attributes.

7. **Error taxonomy**: All `FerrumConnectionError` raises now pass
   `category=` keyword (from W1-D's structured fields). Pool-not-open →
   `category="config"`; connection failure → `category="connection"`; shutdown
   → `category="connection"`; drain timeout → `category="timeout"`.

8. **Non-PG driver compat**: New config knobs only passed to asyncpg driver
   (other drivers have fixed `__init__` signatures). `Connection.open()`
   checks the DSN scheme before passing new kwargs to `get_driver_for_dsn()`.
