## Execute

### Decisions

1. **Codec contract design**: Separated immutable `CodecMeta` (stored in `FieldMeta` at class-definition time) from runtime `FieldCodec` (resolved at query time by W2-B). This keeps model metadata immutable and allows key rotation without model redefinition.

2. **Encryption implementation**: Used stdlib-only authenticated encryption (encrypt-then-MAC with random nonce, SHA-256 keystream, HMAC-SHA256 authentication). No external crypto dependency (`cryptography` not in uv env). The construction is cryptographically sound: random nonce per encryption, separate enc/MAC key derivation via HMAC, constant-time MAC comparison.

3. **Key provider protocol**: Defined `KeyProvider` Protocol with `get_key(key_id) -> bytes` and `key_ids() -> tuple[str, ...]`. Keys are injected at codec construction time, never stored in model metadata. Key rotation works by changing the key provider, not the model.

4. **PII redaction**: Every codec has a `redact(value) -> str` method that returns a redacted representation. For PII fields (`codec_meta.pii=True`), the redaction includes `[REDACTED:pii:...]`. For encrypted codecs, it includes `[REDACTED:encrypted_...:key_id=...]`. Never the raw value.

5. **Field type override**: Codec kind determines the PostgreSQL field_type via `_CODEC_FIELD_TYPE_OVERRIDES` mapping. This ensures DDL and SQL compilation use the correct PostgreSQL type (e.g., `encrypted_string` → `bytes`/`BYTEA`, `citext` → `citext`/`CITEXT`).

6. **Rust metadata**: Added `Citext`, `Inet`, `Domain` variants to `FieldType` enum in `metadata.rs`. The Rust side only needs the field_type for type casting and operator validation — the codec itself is Python-only. `domain_name` is stored in Python-side `FieldMeta` (not sent to Rust boundary).

7. **No queryset.py edits**: As instructed, hydration integration is deferred to W2-B. The codec contract is defined in `models.py` only. The `FieldCodec` protocol, `CodecMeta`, `KeyProvider`, concrete codecs, and factory registry are all in `models.py` and `registry.py`.
