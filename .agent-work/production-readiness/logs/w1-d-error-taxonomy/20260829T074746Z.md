## Execute

### Decisions

1. **Closed category enum**: Defined `ERROR_CATEGORIES` as a `frozenset[str]` containing all categories derived from PostgreSQL SQLSTATE classes plus Ferrum-level categories. Backward-compatible with existing `category` values (`compile_error`, `integrity_error`, `unique_violation`).

2. **Sanctioned fields on base class**: Added `sqlstate`, `category`, `constraint`, `model`, `operation` as attributes on `FerrumError` base class with `None` defaults. `__init__` accepts them as keyword-only args. Subclasses with existing `__init__` (FerrumCompileError, FerrumIntegrityError) pass through via `super().__init__`.

3. **Class-level category defaults**: Non-mapped exceptions (FerrumConfigError, FerrumNotFoundError, etc.) have class-level `category` defaults (e.g. `category = "config"`).

4. **New asyncpg mappings**: Added mappings for DeadlockDetectedError (40P01→deadlock), SerializationError (40001→serialization), LockNotAvailableError (55P03→lock_timeout), AdminShutdownError/CrashShutdownError/CannotConnectNowError (57P01/57P02/57P03→failover), InvalidTransactionStateError (25xxx→invalid_transaction_state), TooManyConnectionsError (53300→pool_exhaustion), UndefinedFunctionError (42883→undefined_function). Existing mappings updated with sqlstate/category. QueryCanceledError now has category=query_cancellation.

5. **Context threading**: `map_db_error` now extracts `model`/`operation` from the `context` dict and threads them onto mapped exceptions via the sanctioned field set.

6. **Hooks**: Added `category` to `_TIER_A_KEYS`. Added optional `category` parameter to `query_failure()` and `hydration_failure()`. `QueryTimer.__exit__` extracts `category` from FerrumError exceptions via `getattr(exc_val, "category", None)`.

7. **PyO3 boundary**: No Rust code changes needed. `map_native_error` in Python sets `category` on mapped exceptions (`compile_error`, `hydration`, `internal`). PyO3 panics remain catchable Python exceptions (no change).

8. **`_extract_sqlstate` and `_sqlstate_to_category` helpers**: Added for migration_op_failure to set sqlstate/category on FerrumMigrationError, and for the generic PostgresError fallback in map_db_error.

9. **No DETAIL as opt-in field**: Per task contract, DETAIL is never added as an opt-in field at any tier.
