## Trigger

SecurityEngineer verdict `changes_required`

Finding 1 (minor — defense-in-depth): `_append_for_update_clause` in
`python/ferrum/queryset.py` quoted `FOR UPDATE OF` table names with `f'"{t}"'`
without escaping embedded double quotes, inconsistent with Rust
`Dialect::quote_ident` (`crates/ferrum-sql/src/dialect.rs:61-69`) which doubles
`"` as defense-in-depth. Identifiers are metadata-sourced (not user input), so
this is not a §3 SQL-injection violation, but §3 treats defense-in-depth in new
SQL emission as a release-qualification gate.

## Pre-existing changes

None relative to base revision — this run is a corrective fix on top of the

## Commands and meaningful output

### Fix applied

`python/ferrum/queryset.py` line 309 (`_append_for_update_clause`):

Before:
```python
parts.append("OF " + ", ".join(f'"{t}"' for t in of))
```

After:
```python
parts.append("OF " + ", ".join(f'"{t.replace(chr(34), chr(34) * 2)}"' for t in of))
```

This doubles any embedded `"` in the metadata-sourced table name, matching the
Rust `Dialect::quote_ident` defense-in-depth pattern. No comments added (per
AGENTS.md).
