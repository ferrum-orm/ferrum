5. **`test_schema_transaction_rejects_unregistered_schema`** (integration, live PG):

6. **`test_schema_transaction_rejects_injection_identifier`** (integration, live PG):
   an SQL-injection attempt in the schema name is rejected by the identifier
   regex BEFORE the allowlist check, even if artificially added to the
   allowlist — the no-raw-SQL §2.9 contract applied to schema selection.

7. **`test_shard_router_resolves_trusted_key_to_explicit_connection`**
   (integration, live PG): `ConnectionRegistry` opens independent PostgreSQL
   pools; `ShardRouter` resolves a trusted key to an explicit Connection /
   Transaction; distinct keys resolve to distinct pools; a bad resolver
   raises `FerrumConfigError`; after `close()`, `get()` raises.

8. **`test_select_for_update_skip_locked_skips_locked_rows`** (integration,
   live PG): `select_for_update(skip_locked=True)` lets a second transaction
   race for queued rows without blocking on rows already locked by a peer —
   mirroring Onyx's `_claim_next_processing_file()` pattern.

9. **`test_select_for_update_nowait_raises_lock_timeout`** (integration, live
   PG): `select_for_update(nowait=True)` fails fast with
   `FerrumTimeoutError` (category `lock_timeout`) when a row is already
   locked — mirroring Onyx's `document.py` `.with_for_update(nowait=True)`.

10. **`test_encrypted_string_codec_round_trip_with_injected_key_provider`**:
    `EncryptedStringCodec` encrypts a string to bytes via an injected
    `KeyProvider`, decrypts back, and encryption is non-deterministic (random
    nonce per call).

11. **`test_encrypted_json_codec_round_trip_with_injected_key_provider`**:
    `EncryptedJSONCodec` serializes a JSON value, encrypts to bytes, and
    decrypts back to the original structure; non-deterministic.

12. **`test_encrypted_codec_rejects_wrong_key_with_mac_failure`**: decrypting
    ciphertext with the wrong key fails authentication and raises
    `FerrumCodecError` — the encrypt-then-MAC authentication property.

13. **`test_encrypted_codec_factory_requires_key_provider_at_query_time`**: the
    encrypted codec factory raises `FerrumCodecError` when no `key_provider`
    is supplied — keys are never hardcoded in model metadata.

14. **`test_encrypted_codec_redact_never_exposes_plaintext_or_key`**: the
    codec's `redact()` method never returns the raw value, ciphertext, or key
    material — only a placeholder carrying codec kind and key id (§3 PII
    redaction).
