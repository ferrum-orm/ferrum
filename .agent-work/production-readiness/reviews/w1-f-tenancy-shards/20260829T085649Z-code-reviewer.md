  GUC *name* `"search_path"` is a literal.

#### routing.py (new, 365 lines)

- `PoolConfig` frozen dataclass mirrors `Connection.__init__` exactly (verified
  against `connection.py:184-204` — every field name and default matches).
- `ConnectionRegistry.__init__` validates `parallelism >= 1`, non-empty
  configs, non-empty shard names, and calls `_ensure_postgres_dsn` for every
  config — structural enforcement of the PostgreSQL-only contract.
- `start()` opens pools with bounded `asyncio.Semaphore`; on `BaseException`
  rolls back already-opened pools (`return_exceptions=True` on the rollback
  gather so cleanup itself can't mask the original error). Post-open, populates
  `_conns` from the `opened` list preserving insertion order.
- `get()` raises `FerrumConfigError` for closed / unknown / not-started shards
  with distinct, actionable messages.
- `health_check()` probes concurrently; a failing pool is reported `False`
  without aborting the rest. The `except Exception:` at line 246 is intentional
  and documented — it is NOT a bare except (catches `Exception`, not
  `BaseException`) and does not swallow (records `False`). Acceptable.
- `close()` is idempotent (`_closed` guard), bounded parallel, uses
  `return_exceptions=True` so one failing close does not mask others.
- `ShardRouter` wraps registry + caller-supplied `resolver`; `connection_for`
  / `transaction_for` resolve the trusted key and delegate. `transaction_for`
  forwards `isolation`/`readonly`/`deferrable`/`deadline` — matches
  `Connection.transaction()` signature exactly (`connection.py:457-464`). No
  `platform_scoped` flag; no implicit routing; no model-metadata inspection.
