## Findings

**C1 — Minor: `__mro__` assertions use `# type: ignore[assert_type]`**
(test_typing_contract.py:47-49)
- Severity: low (style/clarity)
- The accepted-use fixture accesses `_native.FerrumInternalError.__mro__[1]`
  and assigns to `type`, suppressing `assert_type` with
  `# type: ignore[assert_type]`. This weakens the assertion: the intent is
  to verify the exception inherits `RuntimeError`, but `__mro__[1]` is
  fragile (positional) and the ignore defeats the type check. The runtime
  test `test_stub_exceptions_inherit_runtime_error` (line 170) already
  enforces the inheritance via text scan, so this is belt-and-suspenders
  rather than load-bearing.
- Required correction: none. The runtime test covers the invariant. A
  future improvement could use `issubclass`-shaped static assertion without
  the ignore, but this is non-blocking.
