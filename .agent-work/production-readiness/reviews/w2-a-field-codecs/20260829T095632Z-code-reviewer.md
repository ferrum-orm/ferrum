Non-blocking for W2-A — codec not yet wired into queryset. |

This is defensive but slightly surprising — asyncpg returns BYTEA as `bytes`/`memoryview`, not `str`. | Acceptable defensive coding. If the fallback is never exercised in practice, consider removing it. Non-blocking. |
